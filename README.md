# Igor Grybek — Capital, Operations & Technology Portfolio

This repository hosts the official GitHub Pages deployment for **Igor Grybek** (Capital Operations, Corporate Banking & Technology Decision Systems).

Live website: [https://igorgryb.github.io/](https://igorgryb.github.io/)

### Overview
This portfolio presents interactive case studies, multi-dimensional decision models, and executive architectural briefs across:
- **Private Capital & Infrastructure:** Asset governance, AIFMD fund operations, and financing feasibility.
- **Quantitative Risk & Financial Engineering:** Capital allocation, real-options lattices, and stochastic liquidity modeling.
- **Enterprise AI & Applied Systems:** Governed RAG provenance, industrial telemetry, AEC documentation traceability, and transaction state machines.

### Structure
- `index.html`: Main landing page and cross-domain project matrix.
- `*-case-study.html`: In-depth executive case studies for proprietary technology systems.
- `profile-*.html`: Audience-specific professional profiles (Private Capital, Quant/Risk, AI/Data/Product).
- `downloads/`: Executive PDF briefs, decision model workbooks, and presentations.
- `.nojekyll`: Disables Jekyll processing on GitHub Pages to ensure raw assets and styles are served directly.
